# Lumen — Impeccable context

Full product context is in `PRODUCT.md`; the design system is in `DESIGN.md`. Both are binding. This file carries the summary the Impeccable skills look for.

## Design Context

### Users
Mac users who keep their own video and music files and want to watch them properly, on the Mac or on a TV across the room. Keyboard-comfortable, usually sitting back in a dim room. Three jobs: watch (open a file, it plays, chrome gets out of the way, resume tomorrow), adjust (fix subtitles, sound or picture in seconds without leaving the film), send (cast the file and its subtitles to a TV and keep controlling it from the Mac).

### Brand Personality
Calm, precise, cinematic. Quiet until asked; exact like a well-made instrument; built around the picture, with chrome that behaves like house lights. The interface should evoke confidence and ease, never excitement.

### Aesthetic Direction
A precision instrument for light: lens-barrel engraving, a light-meter dial, a Braun clock with one yellow second hand. Matte near-black with ivory markings, hairlines, and a thin accent needle ("scale and needle") as the shared control language and brand mark. Dark-first with a light theme; one user-selectable accent, default Limelight (OKLCH hue 106); neutrals tinted toward the accent hue. Plus Jakarta Sans throughout (fixed by the brief), tabular numerals for anything that changes or aligns. Motion is 150–200 ms ease-out, opacity and transform only, reduced-motion respected.

Anti-references: generic SaaS dashboards, purple gradients, cards inside cards, glass panels with glow, neon on dark, any other player's layout or branding.

Constraints: the video is a native layer beneath a transparent web view, so CSS backdrop blur cannot sample it and is not used. The web view must run on Safari 15-era WebKit (macOS 12), so Tailwind 3.4 and no container queries, `color-mix()`, `@property` or the Popover API. WCAG 2.2 AA, full keyboard access, VoiceOver labels.

### Design Principles
1. The picture comes first: anything over the video must justify itself and leave on its own.
2. One way to reach everything: every action has a name, a shortcut, a tooltip showing it and a palette entry, all from one registry.
3. Adjust while watching: picture and sound controls sit beside the video and apply live.
4. Say what happened: keyboard changes are confirmed on screen in words and numbers.
5. Never fake it: no placeholder data, no dead buttons; unavailable things say why.
